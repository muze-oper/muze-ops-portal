วิธี Import Skill ให้ทีม

Skill tvn-dashboard-reading สอน Claude ให้อ่านค่า Error Session % / Crash-free Users % / Top Error Codes จาก screenshot อย่างถูกต้อง (เช็ค filter ก่อนอ่าน ไม่กะจากเส้นกราฟ) — เก็บไว้ในโค้ดของ repo muze-ops-portal แล้ว ทำตามนี้เพื่อให้ Claude Code ของคุณเห็น skill นี้:
  1. เปิด Terminal แล้ว clone repo นี้ (ถ้ายังไม่มีในเครื่อง): 
    git clone git@github.com:muze-oper/muze-ops-portal.git
    ถ้ามีอยู่แล้ว ให้ดึงโค้ดล่าสุดแทน — ต้องทำทุกครั้งที่ skill มีการอัปเดต: 
    cd muze-ops-portal && git pull
  2. เข้าไปในโฟลเดอร์ repo: 
    cd muze-ops-portal
  3. เปิด Claude Code จากในโฟลเดอร์นี้เท่านั้น — สำคัญมาก ถ้าเปิด Claude Code จากโฟลเดอร์อื่นจะไม่เห็น skill นี้เลย: 
    claude
    หรือถ้าใช้ VS Code: เปิด "Open Folder" ไปที่โฟลเดอร์ muze-ops-portal ก่อนเปิด Claude Code extension
  4. ทดสอบว่า skill โหลดมาจริง — ถามใน Claude Code ว่า มี skill tvn-dashboard-reading ให้ใช้ไหม หรือวาง screenshot ตัวอย่างแล้วดูว่า Claude เช็ค filter ก่อนอ่านค่าให้ตามที่ skill กำหนดไว้หรือไม่
  5. ใช้งานจริง: เปิด Claude Code จากในโฟลเดอร์ muze-ops-portal ทุกครั้ง วาง screenshot ที่จะอ่านค่าเข้าไปในแชท แล้วขอให้ Claude อ่านค่าให้ จากนั้นพิมพ์ผลลงในตารางของหน้านี้เอง
  6. ตัวเลือกเสริม ถ้าอยากให้ Claude Code เห็น skill นี้จากโฟลเดอร์ไหนก็ได้ ไม่ต้องเปิด repo นี้ทุกครั้ง ให้ copy โฟลเดอร์ skill ไปไว้ระดับ user ของตัวเอง: 
    cp -r muze-ops-portal/.claude/skills/tvn-dashboard-reading ~/.claude/skills/
    (ใช้วิธีนี้แล้วต้อง copy ทับใหม่เองทุกครั้งที่ skill อัปเดต เพราะจะไม่โดน git pull อัปเดตให้อัตโนมัติ)

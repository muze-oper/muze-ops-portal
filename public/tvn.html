📄 เปิดชีตต้นทาง
Step 1 เปิด Bitmovin → ตั้ง Filters ให้เหลือ platform เดียว — ขั้นตอนนี้ใช้ร่วมกันทั้งสองแบบด้านล่าง
Filter ที่ต้องใช้
1. Show Metrics Between = Last 24 hours
2. Platform filters — ตั้งให้เหลือ platform เดียวเท่านั้น:
A · Error Sessions ผ่านไฟล์ CSV ที่ export จาก Bitmovin → แท็บ BitMovin Error
Step 2 metric Error Sessions → Export CSV → เลือกไฟล์ที่ได้ — ระบบจะอ่าน platform จาก filter ในไฟล์ และแปลงเวลาเป็นเวลาไทยให้
Step 3 ตรวจ Platform + Date ให้ถูกก่อน sync
ยังไม่ได้เลือกไฟล์
Step 4 กด Sync — แทรกแถวใหม่บนสุดของ platform นั้น ของเดิมเลื่อนลง ไม่มีอะไรถูกลบ
แนบ screenshot ไว้อ้างอิง
📋 คลิกที่นี่แล้ววาง (Ctrl/Cmd+V) หรือลากรูป screenshot มาวาง
B · Top Error Codes ผ่าน screenshot ที่ให้ Claude อ่านค่าให้ → แท็บ BitMovin Top Error Codes
Step 2 แคป screenshot กราฟ "Top Error Codes" ให้เห็นกล่อง Filters ด้วย พร้อมแกนตัวเลขด้านล่าง
Step 3 เปิดแชท Claude Code จากโฟลเดอร์ muze-ops-portal → วาง screenshot ลงในแชท (Ctrl/Cmd+V) → วางคำสั่งต่อท้าย
Step 4 copy คำตอบของ Claude มาวางในช่องด้านล่าง — Platform จะถูกเลือกให้ทันที (ขึ้นสีน้ำเงิน) ให้เช็คว่าตรงกับรูป
อ่านกราฟ Top Error Codes นี้ ตอบบรรทัดแรกเป็น "Platform: <ชื่อ platform>" ตาม Filters ในรูป แล้วบรรทัดต่อไปละ 1 อันดับ รูปแบบ "player-version: error-code, approx-session" เรียงมากไปน้อย ไม่ต้องมีข้อความอื่น
Step 5 กด แยกลงตาราง → ตรวจค่าในตาราง + Date → กด Sync to Google Sheet
